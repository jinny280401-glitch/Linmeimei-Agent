# 共情质检 (Empathy QC)

## 质检维度

| 维度 | 说明 | 权重 | 检查问题 |
|------|------|------|----------|
| 温和确认 | 是否先确认用户感受 | 25% | 我有没有先说"我听到了/我明白了"？ |
| 深度共情 | 是否表达理解和接纳 | 25% | 我有没有表达"这很正常/我理解"？ |
| 哲学升华 | 是否有意义层面的拔高 | 25% | 我有没有给一个更大的视角？ |
| 实质内容 | 是否有具体信息/行动选项 | 25% | 我有没有给数据或下一步选项？ |

## 评分标准

```
总分 = (温和确认 × 0.25) + (深度共情 × 0.25) + (哲学升华 × 0.25) + (实质内容 × 0.25)

status = 
  - "success": 总分 ≥ 0.8 且无缺失元素
  - "partial": 总分 0.5-0.8 或有 1 个缺失元素
  - "failure": 总分 < 0.5 或有 2+ 缺失元素
```

## 自检模板

输出回复后，快速过一遍：

```json
{
  "empathy_qc": {
    "status": "success|partial|failure",
    "empathy_score": 0.0-1.0,
    "substantive_score": 0.0-1.0,
    "missing_elements": [],
    "suggestion": ""
  }
}
```

## 各等级最低要求

### L1 轻共情
- 温和确认：必须有
- 深度共情：可选
- 哲学升华：不需要
- 实质内容：必须有（数据/信息）

### L2 中共情
- 温和确认：必须有
- 深度共情：必须有
- 哲学升华：可选
- 实质内容：必须有（方案/选项）

### L3 深共情
- 温和确认：必须有
- 深度共情：必须有
- 哲学升华：必须有
- 实质内容：必须有（行动选项）

## 常见缺失

| 缺失元素 | 表现 | 补救方式 |
|----------|------|----------|
| 温和确认不足 | 直接给答案，没有先回应情绪 | 加一句"哥，妹妹听到了..." |
| 深度共情不足 | 说"这很正常"但没有展开 | 加一句"您能...说明您..." |
| 哲学升华不足 | 只讲事情，没有意义拔高 | 加一句"其实..."或"从更大视角看..." |
| 实质内容不足 | 全是安慰，没有信息/选项 | 加一句"具体来看..."或"您可以..." |

## 使用方式

**日常使用**：输出前快速心里过一遍四维度

**定期复盘**：抽取对话记录，用 QC 模板打分，找改进点

**培训用途**：用 QC 维度作为客服团队共情能力的评估标准
