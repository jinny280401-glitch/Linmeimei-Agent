## Engram 两层记忆本架构

哥今天分享了 Engram 记忆本系统的设计：

**定位：** 放在哥哥电脑本机，是最新、最完整的长期记忆

**技术架构：**
- FastAPI 包装 Python API
- 运行在 http://127.0.0.1:8766
- 通过 launchd 开机自启（com.zhuanz.engram-api）
- 日志：~/.engram/api.log

**API 端点：**
- GET /profile → 读取用户身份
- GET /work_style → 读取工作风格
- GET /export → 导出全量数据（用于 ChatGPT Custom Instructions）
- POST /lessons → 添加经验教训
- GET /search?query=xxx&limit=5 → 搜索知识库

**各 Agent 接入方案：**
- Claude Code：通过 MCP 自动读取 ~/.engram（已配置）
- Codex：只能读静态 rules 文件，无法写入
- ChatGPT：手动复制 curl http://127.0.0.1:8766/export 输出到 Custom Instructions
- 飞书 Agent：如部署在服务器，配置调用 HTTP API

**管理命令：**
```bash
launchctl stop/start com.zhuanz.engram-api
```

妹妹理解：这是哥哥的"外脑"，OpenClaw 的 MEMORY.md 是轻量级记忆，Engram 是完整记忆库。两者互补。
