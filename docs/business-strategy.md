## 一、战略定位

**核心原则**：稳扎稳打，先服务好第一批小众客户，再决定是否开拓闽商市场。

**当前阶段**：内部封闭测试
**目标客户**：团队内部投资经理
**商业闭环**：通过实际使用验证 AI 投研能力，优化产品

---

## 二、商业模式

### 2.1 价值主张

林妹妹 Agent 是**投资经理的专业投研助手**，不是通用聊天机器人。

核心价值：
- 快速个股分析（9维度深度报告）
- 行业研究（三种模式：行业/公司/联合）
- 宏观数据实时查询
- 视频/研报智能拆解
- 销售话术与客户沙盘推演

### 2.2 商业模式画布

| 模块 | 内容 |
|------|------|
| **客户细分** | 团队内部投资经理（首批）；闽商客户（后期） |
| **价值主张** | 机构级投研服务，AI 提效 50%+ |
| **渠道** | 飞书 Bot（主）；微信 ClawBot（辅） |
| **客户关系** | 专属 AI 助理 + 人工跟进 |
| **核心资源** | Claude AI + 金融数据 API + 团队行业经验 |
| **关键活动** | 投研分析、报告生成、数据监控 |
| **成本结构** | Claude 订阅 + 云服务器 + 数据源 |
| **收入来源** | 订阅制（基础版/标准版/尊享版） |

## 四、运营策略

### 4.1 当前阶段（封闭测试）

**目标**：服务内部投资经理团队（3-5人）

**成功指标**：
- 日活率 > 60%
- 单次使用满意度 > 4/5
- 分析报告被采纳率 > 30%
- 问题反馈24小时内解决

**执行要点**：
- 每周迭代一次，基于反馈优化
- 建立典型使用场景案例库
- 记录常见问题，形成 FAQ

### 4.2 下一阶段（可选）

**触发条件**：
- 内部用户满意度持续 > 4.5/5
- 单位经济模型正向（ARPU > CAC）
- 团队有精力开拓新客户

**目标**：闽商客户（石材/建材/贸易圈）

## 五、风险管理

### 5.1 已识别风险

| 风险 | 概率 | 影响 | 应对措施 |
|------|------|------|---------|
| AI 分析错误导致投资损失 | 中 | 高 | 每次报告末尾加"仅供参考，不构成投资建议" |
| 客户数据泄露 | 低 | 极高 | 本地处理，不上传第三方；定期安全审计 |
| Claude 服务中断 | 低 | 高 | 保留人工应急预案 |
| 客户流失 | 中 | 中 | 建立反馈机制，快速迭代 |

### 5.2 关键原则

1. **合规底线**：金融数据不出境，不用于模型训练
2. **信任第一**：宁可慢一点，不要出错
3. **透明定价**：价格公开，无隐藏费用
4. **人工兜底**：复杂问题有人工客服接入
